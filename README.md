Kantinenettside

En nettside for en kantine der man kan se dagens meny og kantinas faste varer.

hvordan det funker
hjemeside med lenker til meny og varer og kontakt
meny siden som viser dagens varme mat
varer siden der varene er gruppert etter kategori som drike, frukt ok snacks
kontaktside med åpningstider og kontaktinformason
